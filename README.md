# The Attention Machine Skills

Give your AI a raw recording and get back a finished Reel: hook first, rambling gone, captions on, sound ready for the feed. This is the same editing tech that runs [The Attention Machine](https://www.attentionmachine.ai), packed into a skill for Claude Code and Codex.

**It's the most advanced AI video editing skill out there, and it's completely free.**

```bash
npx skills add robinebers/attentionmachine-skills
```

## What it does for you.

You talk to the camera. It does the rest.

- Opens on your best hook, even if you said it last
- Keeps your best take and drops the rambles
- Cuts the ums, the long pauses and the coughs
- Clean cuts, so no word gets clipped
- Captions with your name and numbers spelled right
- Titles, logos, pictures and animations where they help
- Copies the style of any video you like
- Reels by default, YouTube and LinkedIn when you ask

## What you need.

- Claude Code or Codex ($20/mo is enough to start)
- Some tech tools that the skills install (Node.js, ffmpeg, etc)
- An ElevenLabs account for transcription (ears for your AI)
- Remotion (the motion graphics and layouts for your videos)

**Note:** Remotion is free for companies up to 3 employees.

## How to use it.

Install it with the command above, then tell your AI "edit this video" and give it the file.

It walks you through the rest, including your first setup. No settings to learn.
